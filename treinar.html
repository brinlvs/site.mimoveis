Treinar a assistente de orçamentos

Aqui a equipe ensina a assistente: preços, cores, tamanhos, regras e respostas. Para testar, abra a conversa no botão no canto da tela.

Área interna. Não divulgue este endereço. O que você altera aqui fica salvo neste navegador. Para valer para todos os visitantes, use Baixar treinamento.js e substitua o arquivo js/treinamento.js do site. Este site é estático e não tem senha: para proteger a página de verdade seria preciso um servidor.
